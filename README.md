# ✨ Fika Cuisine — Version finale V1
Application Android personnelle de cuisine.

Fonctions incluses :
- suggestions adaptées à la saison et au mode choisi
- bouton « Proposer autre chose »
- « Surprends-moi »
- modes Normal, Rapide, Économique et Ramadan
- historique local quotidien
- favoris
- recherche de plats selon les ingrédients présents
- menu hebdomadaire
- cuisine algérienne et internationale de base
- demande d'autorisation de notifications

Cette version reste hors ligne pour les recettes intégrées. Les fonctionnalités Internet/IA et notifications planifiées nécessitent une V2 avec services supplémentaires.
